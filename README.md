# meu-portifolio-doc
Documentação de portifólio MkDocs

## Ambiente Virtual

* `mkdocs new`
* `python -m venv .venv`
* `source .venv/bin/activate`
* `pip istall -r requirementes.txt`

## Projetos com MkDocs

* `mkdocs new .`
* `echo > docs/index.md` Apenas para deixar o arquvo em branco
* `mkdocs gh-deploy` Publicação do Site
